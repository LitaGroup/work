# 数据与指标



增加栏目`数据`，内部子导航包括：

- 概览
- 报表
- 监控
- 指标



## 技术架构



dataworks(三方) -> lita-work(平台) -> postgresql(元信息存储)+tdengine(存储) -> lita-work(展示+监控)



其中，tdengine的存储为：

```sql
CREATE DATABASE lita
  PRECISION 's'
  KEEP 7300
  DURATION 30
  BUFFER 32
;

create stable `meters`(
  ts      TIMESTAMP,
  value 	FLOAT		-- 值是什么
) TAGS (
  locale VARCHAR(8),	-- 所在的大区值，通常为：in/vi/ko/ph/zh/-
  name VARCHAR(32)		-- 指标的hash值，对应meta元定义中
);


-- index_meta 元定义

create table index_meta (
  id xxx
  name xxxx
  hash xxxx
  ....
) xxxxxxx

create table metrix_monitor_define(
   condition -- 表达式，变量 返回 true / false
)
```
